# План: «Герб семьи» — интерактивный конструктор для групповых психологических практик

## Контекст

Для групповых практик нужен сайт на GitHub Pages, где участник создаёт герб своей семьи из рабочих сфер, животных, орнаментов, цветов и символов, а затем скачивает его в PNG, PDF и SVG. Каталог `/home/yinon/Projects/family-crest` пуст, git не инициализирован, проект создаётся с нуля.

Решения, принятые вместе с вами:
- Интерфейс только на русском, но все тексты хранятся отдельно от кода.
- Два равноправных старта: **чистый лист с полной свободой** и **гибкий шаблон**, который можно менять как угодно.
- Для практики: значения символов и цветов, подсказки-вопросы, рассказ о гербе во второй части PDF.
- Публичный репозиторий `yinon-mitin/family-crest`, адрес сайта `https://yinon-mitin.github.io/family-crest/`.

Сервера нет: всё, что вводит участник, остаётся в его браузере.

## Стек

| Что | Чем | Почему |
|---|---|---|
| Сборка и язык | Vite 8, TypeScript | статическая сборка для Pages |
| Интерфейс | Preact 11 + `@preact/preset-vite` | маленький вес, важно для телефонов |
| Символы | `@iconify-json/game-icons` (CC BY 3.0) | 4134 единых по стилю значка, в сборку попадает только отобранная часть |
| Текст девиза | `opentype.js` + PT Serif и Cormorant (OFL, есть кириллица в WOFF) | буквы превращаются в контуры, поэтому файл выглядит одинаково на любом устройстве |
| PDF | `jspdf` + `svg2pdf.js` | векторный PDF |
| Тесты | Vitest, Playwright | локально установлены Chromium и WebKit, есть `pdftoppm` |

## Главная идея архитектуры

**1. Одна модель документа.** Чистый лист и шаблон отличаются только начальным содержимым, поэтому из шаблона можно уйти в полную свободу в любой момент.

```ts
type Layer = ShieldLayer | SymbolLayer | OrnamentLayer | TextLayer;
interface Base { id; x; y; scale; rotation; flipX; hidden; locked; note: string }
// ShieldLayer: форма, деление на поля, цвет и узор каждого поля, обводка
// SymbolLayer: id символа, цвет, slot?: номер поля (привязка)
// OrnamentLayer: рамка, венок, виньетка, корона, лента и т. д.
// TextLayer: текст, шрифт, вид (прямо / дугой / на ленте), цвет
interface CrestDoc { version: 1; background: string | null; snap: boolean; layers: Layer[] }
```

**2. Одна функция отрисовки.** Чистая функция `renderCrest(doc) → строка SVG` используется и в редакторе, и во всех экспортах. Поэтому скачанный файл совпадает с экраном.

**3. Ограничение на SVG.** Только контуры `path`, сплошная заливка и `clipPath`. Никаких `<pattern>`, фильтров, масок, градиентов и `<text>`: именно они чаще всего расходятся между браузером и PDF. Узоры полей разворачиваются в обычные контуры, обрезанные по полю.

### Как устроена гибкость

- **Чистый лист:** пустой холст, привязка выключена. Щит не обязателен, щитов может быть несколько, любой элемент ставится куда угодно.
- **Шаблон:** 6–8 готовых композиций (классический щит, четверочастный, медальон, дерево рода, щит с лентой и др.). Это обычные документы, в них всё можно менять или удалять.
- **Привязка к полям:** символ из шаблона стоит в поле. Если сменить форму щита или деление, привязанные символы сами перестроятся, ничего не теряется.
- **Отвязка:** перетаскивание отвязывает символ, кнопка «Вернуть в поле» привязывает обратно.
- **Для всех элементов:** перетаскивание, поворот, масштаб, отражение, порядок слоёв, дублирование, блокировка, удаление, отмена и повтор.
- **Управление:** ручки и жесты двумя пальцами на телефоне, а также ползунки и клавиатура для тех, кому жесты неудобны.

## Содержимое

Файл `src/data/catalog.ts` содержит ссылку на значок, название, категорию, значение и теги. Около 170 символов, с поиском по названию и значению:

- **Рабочие сферы (~35):** медицина, образование, наука, сельское хозяйство, строительство, IT, право, искусство, музыка, кулинария, шитьё, морское дело, транспорт, торговля и др.
- **Животные (~40):** лев, медведь, волк, орёл, олень, лиса, сова, лошадь, дельфин, слон, лебедь, петух, пчела, бабочка и др.
- **Природа (~25):** дуб, олива, пшеница, горы, волны, солнце, луна, звёзды, огонь.
- **Символы (~35):** ключ, книга, сердце, рука, башня, корона, якорь, свеча, весы, мост, дом.
- **Орнаменты:** рисуются отдельно и настраиваются. Рамки, венки, виньетки, ленты и 8 узоров полей (полосы, шевроны, шахматка, ромбы, чешуя, волны, горошек, горностай).
- **Щиты:** 6–8 форм и 8 делений (целое, вертикальное, горизонтальное, две диагонали, на четыре части, стропило, на три части).
- **Цвета:** 7 геральдических с значениями и свободный выбор любого цвета.

Значки с оружием, черепами и прочими мрачными образами в каталог не входят. Сборочный скрипт останавливается с ошибкой, если названный значок не найден. Это уже важно: при проверке не нашлись `tree`, `heart`, `hammer`, `book`, `ship`, `bull-head`, `tractor`, `keystone`, и для них подбираются другие значки (например, `open-book`, `cargo-ship`, `farm-tractor`).

### Психологическая часть

- **Значения:** показываются при выборе и сформулированы как приглашение («можно увидеть как…»), а не как трактовка.
- **Подсказки-вопросы:** на каждой вкладке есть сворачиваемый блок, он ни к чему не обязывает. Вопросы открытые и не предполагают определённого состава семьи, поэтому подходят и при утрате, усыновлении, разрыве отношений.
- **Заметка «почему я это выбрал(а)»:** есть у каждого элемента и попадает в рассказ о гербе.

Все значения и вопросы я напишу сам, клинической проверки они не проходили. Они собраны в `src/data/catalog.ts` и `src/data/prompts.ts`, чтобы вы могли просмотреть и поправить их до работы с группами.

## Экспорт (`src/export/`)

- **SVG:** результат `renderCrest` плюс сведения об авторстве значков в метаданных.
- **PNG:** отрисовка SVG на canvas, 1024 / 2048 / 4096 px, фон прозрачный или цветной.
- **PDF:** A4. Первая страница содержит герб в векторе и название семьи. Далее идёт рассказ: миниатюра, каждый элемент с его значением и заметкой, с переносом на новые страницы.

Текст рассказа в PDF тоже превращается в контуры, чтобы кириллица всегда отображалась верно. Цена этого: такой текст нельзя выделить и найти поиском в PDF. Символы, которых нет в шрифтах (эмодзи, иврит), редактор не показывает на гербе и предупреждает об этом участника.

## Сохранение и приватность

- Автосохранение в `localStorage` и кнопка «Начать заново», которая полностью очищает данные. Это важно на общем компьютере в группе, поскольку заметки могут быть личными.
- Проект можно сохранить в файл `.json` и открыть позже с проверкой содержимого, чтобы вернуться к гербу после встречи.
- Никакой аналитики, внешних шрифтов и запросов к другим сайтам. Об этом коротко сказано на странице «О сайте».

## Интерфейс

- **Старт:** выбор «Чистый лист» или галерея шаблонов.
- **Компьютер:** слева вкладки (Щит, Рабочие сферы, Животные, Символы, Орнаменты, Текст), в центре холст, справа свойства и слои, сверху отмена и экспорт.
- **Телефон:** холст сверху, вкладки в нижней выдвижной панели, элементы управления не меньше 44 px.

## Структура проекта

```
src/
  model/      doc.ts, history.ts, templates.ts, slots.ts
  render/     renderCrest.ts, shields.ts, patterns.ts, ornaments.ts, text.ts
  export/     svg.ts, png.ts, pdf.ts, download.ts
  ui/         App.tsx, Start.tsx, Canvas.tsx, Handles.tsx, panels/*, Prompts.tsx, About.tsx
  data/       catalog.ts, prompts.ts, tinctures.ts, strings.ts
scripts/build-symbols.ts      отбирает значки из каталога в symbols.json
.github/workflows/deploy.yml  типы, тесты, сборка, публикация на Pages
vite.config.ts                base: '/family-crest/'
README.md, LICENSE (MIT для кода), указание авторства значков и шрифтов
```

Символы подгружаются отдельным файлом, чтобы первый экран открывался быстро. Лицензия значков CC BY 3.0 требует указать авторов: они указаны на странице «О сайте», в README, в метаданных SVG и в конце PDF. В PNG отдельной подписи нет, чтобы не портить изображение герба.

## Порядок работы

1. Создать каркас проекта, `git init`, сборку символов и каталог.
2. Написать модель, историю и `renderCrest` с тестами.
3. Добавить щиты, деления, узоры, орнаменты и текст в контуры.
4. Сделать редактор: холст, ручки, жесты, панели, поиск, адаптивную вёрстку.
5. Сделать старт, шаблоны, привязку к полям и автосохранение.
6. Сделать экспорт SVG, PNG и PDF с рассказом.
7. Написать тексты значений и подсказок, страницу «О сайте».
8. Создать публичный репозиторий через `gh repo create`, закоммитить, запушить, включить Pages с публикацией через GitHub Actions.

## Проверка

- **Модульные тесты (Vitest):** отрисовка детерминирована и использует только разрешённые элементы SVG; смена щита и деления не теряет символы; отмена и повтор; проверка открываемого файла; все значки каталога существуют; у всех элементов есть название и значение.
- **Сквозные тесты (Playwright, Chromium и WebKit, размеры компьютера и телефона):** оба пути от старта до экспорта, перетаскивание, поворот, масштаб, восстановление после перезагрузки, полная очистка, отсутствие запросов к внешним сайтам.
- **Файлы экспорта:** SVG разбирается и содержит кириллицу в контурах; PNG нужного размера и не пустой; PDF проверяется через `pdfinfo` и `pdftoppm`.
- **Сверка глазами:** я сравню скриншоты редактора с PNG и страницами PDF, в том числе шаблоны, узоры, ленту с кириллицей и длинный рассказ.
- **После публикации:** тот же сценарий на живом адресе, чтобы убедиться, что все файлы открываются с правильным путём `/family-crest/`.
